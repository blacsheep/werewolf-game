# 板子与规则：12 人预女猎守

本文件是引擎和所有 agent 的规则依据。规则有变化时只改这里，再让引擎同步。

## 配置

- 12 名玩家，座位 1–12 号（身份 ID `p01`–`p12`）。
- 4 狼人，4 平民，预言家、女巫、猎人、守卫各 1。
- 身份由引擎按种子随机分配，种子写入对局记录，可复盘。

## 胜负：屠边

- 狼人杀光所有平民，或杀光所有神职（预言家、女巫、猎人、守卫），狼人胜。
- 所有狼人出局，好人胜。
- 每次有人出局后立即判定。

## 夜晚顺序

守卫 → 狼人 → 女巫 → 预言家。

- **守卫**：每晚守护一人，可以守自己，不能连续两晚守同一人，可以空守。
- **狼人**：在狼队频道商量，统一刀一人，可以空刀。狼人能看到队友。
- **女巫**：一瓶解药、一瓶毒药，同一晚不能同时使用两瓶。**全程不能自救**。女巫能知道当晚被刀的人（解药用掉后不再告知）。
- **预言家**：每晚查验一人，得知「好人」或「狼人」。
- **同守同救**：同一人被守卫守护又被女巫救，此人死亡（奶穿）。
- 守卫守中被刀者，被刀者存活。

## 白天流程

1. **第一天：警长竞选**（天亮宣布死讯之前）。
   - 想竞选的人上警，从随机一位上警者开始依次发言。
   - 发言结束后可以退水；退水的人不能投票，也不能被投。
   - 没上警的玩家投票，最高票当选；平票的人再次发言 PK 后再投，仍平票则本局没有警徽。
   - 只有一人上警时自动当选；无人上警或全员上警（没人能投票）则没有警徽。
2. **公布昨夜死讯。** 只公布死者，不公布死因。
3. **遗言**：第一夜死亡的玩家有遗言；之后夜里死亡的玩家**没有**遗言；白天被放逐的玩家有遗言。
4. **发言**：警长决定从警左还是警右开始，最后由警长发言并归票。没有警长时，从死者的下一位开始顺序发言（无人死亡则随机）。
5. **放逐投票**：所有存活玩家同时投票，可以弃票。警长的票算 1.5 票。最高票出局。平票的玩家 PK 发言后，其他玩家再投一次；仍平票则当天无人出局。
6. 放逐后发表遗言，然后进入黑夜。

## 警长

- 警长出局时可以把警徽移交给一名存活玩家，或撕毁警徽。
- 警徽流：预言家可以在发言里交代自己出局后警徽给谁、之后验谁，是否这样做由玩家自己决定。

## 猎人

- 猎人被狼刀或被放逐出局时，可以开枪带走一名存活玩家，也可以不开枪。
- 被女巫毒死时**不能**开枪。

## 狼人自爆

- 白天任何发言阶段，狼人可以自爆：立即出局，当天流程结束，直接进入黑夜。没有遗言。
- 警长竞选期间自爆：警徽流失，本局不再有警长。
- 在 agt 中，狼人只能在**轮到自己发言时**自爆（agent 只在被点到时行动）。

## 投票保密

- 投票只能通过引擎的投票工具，不能在群里公开说投谁。
- 全部投完之后，由上帝公布票型。

## 用户批准的补充约定（2026-10-19）

以下补充明确上述规则的结算时序；与上文简写有时序差异时，以本节为准。

1. **首夜死讯在警选后生效**：首夜夜间行动先产生待公布死者，警选期间死亡尚未生效，仍可报名、发言、投票及当选。警选结束后公布死讯、使死亡生效并判胜；警上自爆则按第 4 项提前结束警选并公布。
2. **同夜死亡统一判胜**：同一晚的死亡作为一批同时生效，然后判定胜负，不在同夜各死者之间分别判胜。
3. **终局停止后续动作**：死亡结算一旦判定胜负，立即终局，不再执行遗言、猎人开枪、移交警徽或进入下一夜。猎枪造成新的死亡时立即重新判胜；若终局，也停止队列中剩余的遗言和移徽。
4. **警上自爆保留首夜死亡动作**：警长竞选发言或警选 PK 发言时自爆，警徽流失，先公布昨夜死讯；未触发终局时，首夜死者照常发表遗言，猎人符合原规则条件时照常开枪。这些死亡动作处理完后直接进入下一夜，不恢复警选或当天正常发言、放逐投票。自爆者本身仍按自爆规则无遗言。

## 其余实现补充约定（尚未单独批准）

以下为引擎已有的细节选择，非原规则正文已经规定的内容；保留供确认。除上一节批准内容外，本次不改变这些选择。

- **警上自爆的判胜批次**：记录自爆及警徽流失，公开昨夜死者名单；自爆者与待公布的同夜死者在同一次结算中出局，先统一判胜，再开放死亡后动作。自爆与夜死之间不插入一次独立判胜。同一座位既是待公布死者又自爆时仅出局一次，按自爆处理，无遗言。
- **死亡后动作顺序**：夜死按座位升序，每名死者依次处理合法猎人开枪 → 警徽 → 遗言。枪击导致的新死者需移徽时，追加到现有动作队列末尾；被枪带走无额外遗言。每次枪击死亡后先判胜，再继续队列；队列清空后才继续白天或入夜。警上自爆已使警徽流失，不再移徽；普通白天自爆的警长仍先处理移徽再入夜。
- **同夜死因与同时达成胜利条件**：同一人既中刀又中毒按毒死处理，猎人不能开枪；毒不受守护或解药保护。同批最后狼人和最后平民/神职同时死亡，先按全狼出局判好人胜。
- **投票细节**：每轮不可改票、无超时自动弃票或上帝代投；允许自投；全弃票/无有效票视为无人当选或无人放逐，不产生全员 PK。放逐 PK 排除 PK 当事人；警选 PK 仍仅原不上警者投票，退水者不得重新投票；退水后仅剩一名候选人自动当选。
- **方向与随机细节**：警左按座号递增、警右递减；无警长且多名夜死时从最小座号死者的下一名存活者开始，无死者则按种子随机。警上发言从种子决定的随机候选人起按座号递增循环，PK 按座号递增。
- **技能目标细节**：预言家可自验，不可验已公布死亡者；狼人可刀自身或队友。狼队先协商，由任一存活狼人提交统一刀口，后续重复提交无效。
- **笔记与导出**：笔记只由本人提交/查询，但包含在上帝完局完整审计导出中；警徽流只记录在自愿发言里，不自动安排查验或移徽。
