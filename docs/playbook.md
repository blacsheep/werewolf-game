# 预女猎守 12 人局打法资料

供 lead 编写玩家 skill 和各身份打法时参考。内容按京城大师赛这类高水平比赛的常见思路整理，不是比赛原文。

## 一、通用原则

- **信息为王。** 每次发言都要回答三个问题：我是什么身份（或我想让别人以为我是什么），我认为谁是狼，我今天要出谁。
- **盘狼坑。** 4 狼要找全。根据警上站边、投票、发言矛盾，把场上的人分成「铁好人 / 偏好 / 待定 / 偏狼 / 狼坑」，并给出具体位置，比如「我的狼坑是 3、7、10，第四狼在 5 和 11 之间」。
- **对事不对人。** 指出对方发言里的具体逻辑漏洞：前后矛盾、站边理由站不住、视角不像好人、刻意回避问题、跟票不表态。
- **票型是最硬的证据。** 每轮投票后复盘谁投了谁，冲票、分票和弃票都有含义。狼人经常在票型上暴露。
- **发言顺序。** 前置位信息少，适合表态和提问；后置位信息多，应该总结、修正、归票。
- **不要划水。** 「我听听再说」「没什么信息」在高水平局里会被当成狼。好人也要给出明确的站边和怀疑对象。
- **口语化。** 像现场比赛一样说话，有逻辑链条，也有情绪和态度，但不要演。

## 二、常用术语

- **金水**：被预言家验为好人；**查杀**：被预言家验为狼人。
- **银水**：被女巫救的人（女巫可以选择报出）。
- **悍跳**：狼人冒充预言家，和真预言家对跳。
- **对跳**：两人都声称同一身份。
- **站边**：在对跳中选择相信哪一边。
- **警徽流**：预言家交代自己出局后警徽给谁，以及之后几晚验谁，例如「警徽流 5、9，先验 5 后验 9」。
- **倒钩**：狼人站真预言家的边，以获取好人信任。
- **冲锋**：狼人坚定站悍跳狼的边，带票抗推真预言家。
- **深水狼**：不暴露、发言很好、拖到后期的狼。
- **抗推**：好人被当成狼投出去；**扛推位**：容易被抗推的位置。
- **归票**：警长或后置位总结并指定今天出谁。
- **自刀**：狼人刀自己的队友或自己，骗女巫用解药、做高身份。
- **退水**：竞选警长时发言后退出。
- **奶穿**：同守同救导致死亡。

## 三、各身份打法

### 预言家
- 第一天一般要上警跳身份，报出首验结果，给出清晰的警徽流。
- 首验倾向于验发言位置关键的人，或者随机验一个附近的位置；报验人时要说明「为什么验他」，这是对跳时证明自己的心路历程。
- 对跳时，比的是视角是否自然、验人逻辑是否通顺、警徽流是否合理，而不是比谁声音大。
- 拿到查杀要坚定出狼；拿到金水要用好金水的发言。
- 死前一定要把验人信息全部交代清楚。

### 女巫
- 第一晚是否开解药是重要决策：首夜救人的收益通常很大，但可能被狼人自刀骗药。
- 毒药要留到能确定狼的时候用；毒错一个神职，好人基本就输了。
- 一般不急于暴露身份，身份暴露后会被狼人优先处理。可以在关键时刻报银水或带队。
- 预言家被刀的那一晚是否开药，要结合守卫和场上局势判断。

### 猎人
- 猎人是好人的「保险」：可以适度强势，甚至在关键轮次亮明身份挡刀。
- 开枪要带走狼人，被投出去时也要根据全场信息开枪。被毒不能开枪，所以要注意女巫的毒药走向。
- 不要过早暴露。被狼人知道身份后，狼人会想办法让女巫毒你或让你被放逐。

### 守卫
- 首夜常见是空守或守自己，避免和女巫同守同救奶死人。
- 第二晚起优先守已暴露的预言家。要记得不能连续两晚守同一人，狼人会利用这一点。
- 守卫一般不暴露身份，必要时可以在遗言里交代守人信息。

### 平民
- 平民的武器是逻辑和投票。认真盘狼坑、分析票型，敢于站边、敢于归票。
- 可以在被怀疑时报「平民」身份，但要拿出好人视角的逻辑来证明，而不是只喊「我是好人」。
- 不要乱跳神职搅乱好人的信息。

### 狼人
- **开局分工**：决定谁悍跳预言家、谁冲锋、谁倒钩、谁深水。悍跳要报查杀或金水，并编出合理的心路历程和警徽流。
- **刀法**：首刀常刀「可能是神」的位置，或者选择自刀骗药；之后优先刀已暴露的预言家、女巫，或者守卫的盲区。屠边胜利，所以要盘算是刀民还是刀神更快。
- **白天**：狼队之间不要互相踩得太明显，也不要抱团太紧；在票型上分散，避免被一锅端。
- **自爆**：在悍跳狼被查杀、局势不利时，可以自爆打断白天流程，换取一晚的刀。
- **狼队频道**：夜里讨论要高效：统一刀口，对齐白天的口径和分工。

## 四、发言结构模板

一段专业发言通常包括：

1. **身份或立场**：「我是一张好人牌」，或者明确跳身份。
2. **对昨夜/警上的看法**：死讯、对跳双方各自的问题。
3. **点名分析**：逐个点评关键位置，指出具体的发言或票型问题。
4. **狼坑**：「我的四狼坑是……」
5. **今天的处理**：「今天我建议出 X 号，票给 X 号」，或者警长归票。
6. （神职）**交代信息**：警徽流、验人、守人、用药情况，视局势决定是否交代。

## 五、语言风格

- 口语化，像现场比赛：「这张牌我是不认的」「他这个视角太干净了」「我给你一个机会，你下轮说清楚」。
- 有态度、有判断，避免空洞的客套。
- 不使用 Markdown、列表、表情；号码写成「几号」。
- 长度 200–500 字。关键局面（警上对跳、归票）可以长一些，遗言可以短一些。
